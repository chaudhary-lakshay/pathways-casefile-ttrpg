# Pathways M0 + M1 — Tooling and Rules Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the offline extraction tooling and a pure-Kotlin rules engine that reproduces all 23 published character sheets on the trusted field set, with no UI.

**Architecture:** A JVM-only Gradle build with two library modules — `:core:model` (data types, zero logic) and `:core:rules` (pure functions over those types). Content is extracted from the rulebook PDF and the 23 `.xlsx` sheets by Python scripts in `tools/`, which emit JSON committed to the repo. The engine reads that JSON; it never sees a PDF or a spreadsheet. No Android module exists yet — that arrives at M2.

**Tech Stack:** Kotlin 2.2.0 (JVM, JDK 17), Gradle 9.3.1 (Kotlin DSL + version catalog), JUnit 5, kotlinx-serialization-json, Python 3.12 with `pypdf` and `openpyxl` (both already installed on this machine).

## Global Constraints

- **Spec:** `docs/superpowers/specs/2026-07-25-pathways-companion-design.md`. Every rule below traces to it; where this plan and the spec disagree, the spec wins.
- **The book is the authority; the sheets are fixtures.** Where a published sheet disagrees with the rulebook, encode the book and record the sheet's value as `asPublished`.
- **`:core:model` and `:core:rules` must not depend on Android.** No `android.*` imports, no context, no resources. They are `kotlin("jvm")` modules.
- **Derived values are never stored.** Only purchased state, Beyonder state, and table state are persisted.
- **Basic Speed is stored in quarter-steps as an `Int`.** Never a `Float`, never a `Double`. `basicSpeedQuarters = 18` means 4.50.
- **`1d-3` means `1d6 - 3`.** Not `1d3`. There is no minimum-damage floor in this book; negative results are legal and are the GM's problem, not the engine's.
- **JDK 17.** `java` resolves to `C:\Program Files\Java\jdk-17\bin\java.exe`. There is no standalone `gradle` on PATH — the wrapper is copied in Task 1.
- **Commit after every task.** Never add a `Co-Authored-By` trailer.
- **Package root:** `com.pathways`.
- If a pinned dependency version fails to resolve, bump to the newest patch of the same minor and note it in the commit body. Do not change the major or minor.

```python
"""Extract the rulebook PDF into page text and chapter spans.

Output goes to build/extract/ and is gitignored — it is an intermediate,
not content. Chapter boundaries come from the table of contents on pages
2-3, which lists each chapter's start page; a chapter ends on the page
before the next one starts.
"""
import json, os, pathlib

ROOT = pathlib.Path(__file__).resolve().parent.parent
PDF = pathlib.Path(os.path.expanduser("~/Downloads/Mr.Worms LOM TTRPG Rulebook v6.9d.pdf"))
OUT = ROOT / "build" / "extract"

# (id, title, startPage) read from the table of contents, pages 2-3.
CHAPTERS = [
    ("1",   "Introduction",                  5),
    ("2",   "Core Rules",                    7),
    ("3",   "Character Creation",           10),
    ("4",   "Spirituality",                 33),
    ("5",   "Combat",                       35),
    ("6",   "The Beyonder System",          44),
    ("6.5", "Divination Arts",              53),
    ("7",   "Ritualistic Magic",            60),
    ("7.5", "Summoning Spiritual Creatures", 75),
    ("7.6", "Spirit Vision Guide",          77),
    ("8",   "Equipment & Starting Wealth",  79),
    ("9",   "Sequence 9 Potion Effects",    85),
    ("10",  "Sequence 8 Potion Effects",    97),
    ("11",  "Sequence 7 Potion Effects",   111),
    ("12",  "Sequence 6 Potion Effects",   129),
    ("13",  "Boon Granting",               144),
    ("14",  "Non-Standard Pathways",       146),
    ("15",  "Non-Standard Sequence 8",     153),
    ("A",   "Quick Reference Tables",      159),
    ("B",   "The Political World",         160),
    ("C",   "Orthodox Churches",           162),
    ("G",   "Glossary of Terms",           167),
]


def main() -> None:
    from pypdf import PdfReader

    if not PDF.exists():
        raise SystemExit(f"rulebook not found at {PDF}")

    reader = PdfReader(str(PDF))
    pages = [
        {"page": i + 1, "text": p.extract_text() or ""}
        for i, p in enumerate(reader.pages)
    ]

    last = len(pages)
    chapters = []
    for idx, (cid, title, start) in enumerate(CHAPTERS):
        end = CHAPTERS[idx + 1][2] - 1 if idx + 1 < len(CHAPTERS) else last
        chapters.append({"id": cid, "title": title, "startPage": start, "endPage": end})

    OUT.mkdir(parents=True, exist_ok=True)
    (OUT / "pages.json").write_text(json.dumps(pages, ensure_ascii=False, indent=1), encoding="utf-8")
    (OUT / "chapters.json").write_text(json.dumps(chapters, ensure_ascii=False, indent=1), encoding="utf-8")
    print(f"{len(pages)} pages, {len(chapters)} chapters -> {OUT}")


if __name__ == "__main__":
    main()
```

`tools/extract_sheets.py`:

```python
"""Convert the 23 published .xlsx character sheets into JSON fixtures.

These are FIXTURES, not content. Where a sheet disagrees with the
rulebook the sheet is wrong (spec section 6); we record what it printed
so the engine can show a computed-vs-published diff.

Reads the CharSheetP1 tab only. ThrustTable is content (Task 10), and
Summons is byte-identical boilerplate across all 23 files with no
character data at all.
"""
import glob, json, os, pathlib, re

ROOT = pathlib.Path(__file__).resolve().parent.parent
SRC = pathlib.Path(os.path.expanduser("~/Downloads/LOTM TTRPG Sheets"))
OUT = ROOT / "fixtures"

DIFFICULTIES = {"E", "A", "H", "VH"}


def slug(name: str) -> str:
    return re.sub(r"[^a-z0-9]+", "_", name.lower()).strip("_")


def num(v):
    """Cell -> int when integral, float when not, None when blank."""
    if v is None or v == "":
        return None
    try:
        f = float(v)
    except (TypeError, ValueError):
        return None
    return int(f) if f == int(f) else f


def find(grid, label):
    """Row/col of the first cell equal to `label`, or None."""
    for r, row in enumerate(grid):
        for c, cell in enumerate(row):
            if isinstance(cell, str) and cell.strip() == label:
                return r, c
    return None


def parse_skill(raw: str):
    """'History (Occult)/IQ' -> ('History', 'Occult', 'IQ')."""
    name_part, _, attr = raw.rpartition("/")
    m = re.match(r"^(.*?)\s*\((.*)\)\s*$", name_part.strip())
    if m:
        return m.group(1).strip(), m.group(2).strip(), attr.strip()
    return name_part.strip(), None, attr.strip()


def extract(path: pathlib.Path) -> dict:
    from openpyxl import load_workbook

    ws = load_workbook(str(path), data_only=True)["CharSheetP1"]
    grid = [list(r) for r in ws.iter_rows(values_only=True)]

    def value_right_of(label, offset=1):
        pos = find(grid, label)
        if pos is None:
            return None
        r, c = pos
        return num(grid[r][c + offset]) if c + offset < len(grid[r]) else None

    attributes = {a: value_right_of(a) for a in ("ST", "DX", "IQ", "HT")}

    published = {
        "hp":         value_right_of("HP"),
        "fp":         value_right_of("FP"),
        "will":       value_right_of("Will"),
        "per":        value_right_of("Per"),
        "spi":        value_right_of("SPI"),
        "cor":        value_right_of("CoR"),
        "basicSpeed": value_right_of("BASE SPD"),
        "basicMove":  value_right_of("BASE MOVE"),
        "dodge":      value_right_of("Dodge"),
        "bpTotal":    None,
        "totalSpent": None,
        "unspent":    value_right_of("Unspent", 2),
    }

    # "Budget (BP)" and "Total spent" print as strings like "100 pts".
    for label, key in (("Budget (BP)", "bpTotal"), ("Total spent", "totalSpent")):
        pos = find(grid, label)
        if pos:
            r, c = pos
            for cell in grid[r][c + 1:]:
                if isinstance(cell, str):
                    m = re.search(r"(\d+)\s*pts", cell)
                    if m:
                        published[key] = int(m.group(1))
                        break

    def traits(header):
        pos = find(grid, header)
        if pos is None:
            return []
        r0, c0 = pos
        out = []
        for row in grid[r0 + 2:]:                    # +2 skips the sub-header row
            name = row[c0] if c0 < len(row) else None
            if not isinstance(name, str) or not name.strip():
                break
            if name.startswith("*GURPS"):
                break
            cost = next((num(x) for x in row[c0 + 1:c0 + 8] if num(x) is not None), None)
            out.append({"name": name.strip(), "cost": cost or 0})
        return out

    skills = []
    pos = find(grid, "SKILLS & TECHNIQUE")
    if pos:
        r0, c0 = pos
        for row in grid[r0 + 2:]:
            cell = row[c0] if c0 < len(row) else None
            if not isinstance(cell, str) or not cell.strip():
                break
            text = cell.strip()
            if "/" not in text:                      # category header, e.g. "Social & Utility (56 pts):"
                continue
            rest = [x for x in row[c0 + 1:] if x is not None and x != ""]
            diff = next((str(x).strip() for x in rest if str(x).strip() in DIFFICULTIES), None)
            nums = [num(x) for x in rest if num(x) is not None]
            if diff is None or len(nums) < 2:
                continue
            name, spec, attr = parse_skill(text)
            skills.append({
                "name": name, "specialization": spec, "attr": attr,
                "difficulty": diff, "points": nums[1], "publishedLevel": nums[0],
            })

    return {
        "name": path.stem,
        "attributes": attributes,
        "published": published,
        "advantages": traits("ADVANTAGES AND PERKS"),
        "disadvantages": traits("DISADVANTAGES AND QUIRKS"),
        "skills": skills,
    }


def main() -> None:
    OUT.mkdir(parents=True, exist_ok=True)
    n = 0
    for f in sorted(glob.glob(str(SRC / "*.xlsx"))):
        p = pathlib.Path(f)
        if p.name.startswith("~$"):        # Excel lock file
            continue
        data = extract(p)
        (OUT / f"{slug(p.stem)}.json").write_text(
            json.dumps(data, ensure_ascii=False, indent=1), encoding="utf-8")
        n += 1
    print(f"{n} fixtures -> {OUT}")


if __name__ == "__main__":
    main()
```

`tools/coverage.py`:

```python
"""Report how much of each chapter has been claimed by extracted content.

A content file may declare which source lines it consumed:

    { "sourceLines": { "3": [[1717, 2100]] }, "entries": [...] }

Everything not claimed is counted as unclaimed. A line is "mechanical" if
it contains a die expression, a signed modifier, a point cost, or an
attribute offset — prose without those is flavour and may stay unclaimed.
"""
import json, pathlib, re, sys

ROOT = pathlib.Path(__file__).resolve().parent.parent
OUT = ROOT / "build" / "extract"
CONTENT = ROOT / "core" / "rules" / "src" / "main" / "resources" / "content"

MECHANICAL = re.compile(r"\d+d[-+]?\d*|[+-]\d+\b|\d+\s*pts?\b|\bAttr[+-]\d+")


def main() -> int:
    pages = json.loads((OUT / "pages.json").read_text(encoding="utf-8"))
    chapters = json.loads((OUT / "chapters.json").read_text(encoding="utf-8"))

        spans = claimed.get(ch["id"], [])
        claimed_lines = sum(b - a + 1 for a, b in spans)
        pct = (claimed_lines / total * 100) if total else 0.0

        mechanical = sum(
            1
            for p in body
            for line in p["text"].splitlines()
            if MECHANICAL.search(line)
        )
        unclaimed = max(0, mechanical - claimed_lines)
        if pct > 0 and unclaimed > 0:
            failed = True

                     f"{ch['startPage']}-{ch['endPage']} | {pct:.1f}% | {unclaimed} |")
```

```kotlin
package com.pathways.model

import kotlinx.serialization.Serializable

/**
 * A GURPS dice expression: [count]d[sides] with a flat [modifier].
 *
 * Sides default to 6 and are usually omitted in the book, which creates
 * the notation trap this type exists to close: "1d-3" is 1d6 minus 3,
 * never 1d3. There is no minimum-damage rule in this rulebook, so a roll
 * may legitimately come out zero or negative.
 */
@Serializable
data class DiceExpr(val count: Int, val sides: Int = 6, val modifier: Int = 0) {

    init {
        require(count > 0) { "die count must be positive, was $count" }
        require(sides > 0) { "die size must be positive, was $sides" }
    }

    fun render(): String = buildString {
        append(count).append('d')
        if (sides != 6) append(sides)
        if (modifier > 0) append('+').append(modifier)
        if (modifier < 0) append(modifier)      // already carries its sign
    }

    companion object {
        private val PATTERN = Regex("""^(\d+)d(\d+)?([+-]\d+)?$""")

        fun parse(raw: String): DiceExpr {
            val m = PATTERN.matchEntire(raw.trim())
            require(m != null) { "not a dice expression: '$raw'" }
            val (count, sides, mod) = m.destructured
            return DiceExpr(
                count = count.toInt(),
                sides = sides.ifEmpty { "6" }.toInt(),
                modifier = mod.ifEmpty { "0" }.toInt(),
            )
        }
    }
}
```

```kotlin
package com.pathways.rules

import com.pathways.model.DiceExpr
import kotlin.random.Random

/** Randomness as a dependency, so every roll in the test suite is reproducible. */
fun interface RandomSource {
    /** Returns a value in 1..[sides]. */
    fun roll(sides: Int): Int
}

class SeededRandom(seed: Long) : RandomSource {
    private val rng = Random(seed)
    override fun roll(sides: Int): Int = rng.nextInt(1, sides + 1)
}

fun DiceExpr.roll(source: RandomSource): Int =
    (1..count).sumOf { source.roll(sides) } + modifier
```

```kotlin
import com.pathways.model.Attr
import com.pathways.model.Attributes
import com.pathways.model.BASE_ATTRIBUTE

/**
 * Ch. 3: all attributes begin at 9 for free, and each level above costs
 * twice the one before it. ST and HT are cheap; DX and IQ are not.
 */
object AttributeCosts {

    private fun perLevelBase(a: Attr): Int = when (a) {
        Attr.ST, Attr.HT -> 10
        Attr.DX, Attr.IQ -> 20
    }

    fun costOf(attr: Attr, level: Int): Int {
        require(level >= BASE_ATTRIBUTE) {
            "attributes cannot be bought below $BASE_ATTRIBUTE (was $level); the book gives no refund"
        }
        val base = perLevelBase(attr)
        return (BASE_ATTRIBUTE + 1..level).sumOf { base shl (it - BASE_ATTRIBUTE - 1) }
    }

    fun totalCost(a: Attributes): Int = Attr.entries.sumOf { costOf(it, a[it]) }
}
```

```kotlin
package com.pathways.rules

import com.pathways.model.Difficulty

/**
 * Ch. 3, p. 25-26. Cumulative point totals form a doubling ladder;
 * difficulty decides where the first rung lands relative to the
 * controlling attribute, and each further rung is worth +1.
 *
 * This is NOT vanilla GURPS costing — under GURPS 4e core the ladder is
 * 1/2/4/8/12/16 with +4 per level past Attr+2. Using core costs would make
 * 14 of the 232 published skill levels wrong.
 */
object SkillLadder {

    private val RUNGS = intArrayOf(1, 2, 4, 8, 16, 32, 64, 128, 256)

    fun levelFor(points: Int, difficulty: Difficulty, attributeLevel: Int): Int {
        require(points > 0) { "spend at least 1 point, or use defaultFor()" }
        val rung = RUNGS.indexOfLast { it <= points }
        return attributeLevel + difficulty.firstRungOffset + rung
    }

    /** Null when the skill cannot be attempted untrained at all. */
    fun defaultFor(difficulty: Difficulty, attributeLevel: Int): Int? =
        difficulty.defaultPenalty?.let { attributeLevel + it }
}
```

```kotlin
/** Computed secondary characteristics. Never persisted — spec 3.2. */
data class Secondaries(
    val maxHp: Int,
    val maxFp: Int,
    val will: Int,
    val per: Int,
    val basicSpeedQuarters: Int,
    val basicMove: Int,
    val dodge: Int,
) {
    /** For display only. The engine never computes on this. */
    val basicSpeed: String get() = "%.2f".format(basicSpeedQuarters / 4.0)
}

object SecondaryCharacteristics {

    private const val COST_HP = 2
    private const val COST_FP = 3
    private const val COST_WILL = 5
    private const val COST_PER = 5
    private const val COST_SPEED_QUARTER = 5
    private const val COST_MOVE = 5

    fun of(a: Attributes, d: SecondaryDelta): Secondaries {
        // (HT+DX)/4 expressed in quarters is simply HT+DX. At 9/9 that is
        // 18 quarters = 4.50, matching the book.
        val speedQuarters = (a.ht + a.dx) + d.basicSpeedQuarters
        val wholeSpeed = Math.floorDiv(speedQuarters, 4)
        return Secondaries(
            maxHp = a.st + d.hp,
            maxFp = a.ht + d.fp,
            will = a.iq + d.will,
            per = a.iq + d.per,
            basicSpeedQuarters = speedQuarters,
            basicMove = wholeSpeed + d.basicMove,
            // Ch. 5: Dodge follows Basic SPEED, so a Basic Move purchase does not raise it.
            dodge = wholeSpeed + 3,
        )
    }

    fun costOf(d: SecondaryDelta): Int =
        d.hp * COST_HP +
            d.fp * COST_FP +
            d.will * COST_WILL +
            d.per * COST_PER +
            d.basicSpeedQuarters * COST_SPEED_QUARTER +
            d.basicMove * COST_MOVE
}
```

```kotlin
package com.pathways.rules

import com.pathways.model.*

data class BudgetReport(
    val budget: Int,
    val spent: Int,
    val violations: List<String>,
) {
    val surplus: Int get() = budget - spent
}

/**
 * Ch. 3, p. 11 and p. 19.
 *
 * Budget = 70 + capped disadvantages (max 40) + capped quirks (max 5).
 * Spending must be <= budget, never == budget: surplus is normal and
 * several published sheets leave points unspent.
 */
object PointBudget {

    const val STARTING_TOTAL = 70
    const val MAX_DISADVANTAGES = 40
    const val MAX_QUIRKS = 5

    fun report(
        attributes: Attributes,
        secondaryDelta: SecondaryDelta,
        traits: List<Trait>,
        skills: List<PurchasedSkill>,
    ): BudgetReport {
        fun sumOf(kind: TraitKind) = traits.filter { it.kind == kind }.sumOf { it.cost }

        val rawDisadvantages = sumOf(TraitKind.DISADVANTAGE)
        val rawQuirks = sumOf(TraitKind.QUIRK)
        val budget = STARTING_TOTAL +
            minOf(rawDisadvantages, MAX_DISADVANTAGES) +
            minOf(rawQuirks, MAX_QUIRKS)

        val spent = AttributeCosts.totalCost(attributes) +
            SecondaryCharacteristics.costOf(secondaryDelta) +
            sumOf(TraitKind.ADVANTAGE) +
            skills.sumOf { it.points }

        val violations = buildList {
            if (rawDisadvantages > MAX_DISADVANTAGES) {
                add("Disadvantages total $rawDisadvantages, capped at $MAX_DISADVANTAGES")
            }
            if (rawQuirks > MAX_QUIRKS) {
                add("Quirks total $rawQuirks, capped at $MAX_QUIRKS")
            }
            if (spent > budget) add("Overspent: $spent of $budget")
        }

        return BudgetReport(budget, spent, violations)
    }
}
```

```kotlin
enum class UnarmedStyle { BRAWLING, BOXING, WRESTLING }

/**
 * Ch. 5, p. 37. Parry is a property of a readied weapon, not of a
 * character — a character carrying two weapons has two parry values, and
 * some weapons have none at all.

object ParryBlock {

    fun parryFor(weapon: Weapon, skillLevel: Int): Int? =
        weapon.parryMod?.let { mod -> skillLevel / 2 + 3 + mod }

    fun unarmedParry(style: UnarmedStyle, skillLevel: Int): Int = when (style) {

        UnarmedStyle.WRESTLING -> (skillLevel - 3) / 2 + 3
    }

    fun blockFor(shieldSkillLevel: Int, shieldDb: Int): Int = shieldSkillLevel / 2 + 3 + shieldDb
}
```

```kotlin
package com.pathways.rules

import com.pathways.model.*

data class Context(
    val isNight: Boolean = false,
    val isDarkness: Boolean = false,
    val sequenceDelta: Int = 0,
    val turn: Int = 0,
)

data class Resolution(
    val value: Int,
    val forbidden: Boolean = false,
    val requiresCritical: Boolean = false,
    val applied: List<ModifierId> = emptyList(),
)

object ModifierResolver {

    fun resolve(base: Int, mods: List<Modifier>, target: ModTarget, ctx: Context): Resolution {
        val superseded = mods.mapNotNull { it.supersedes }.toSet()
        val live = mods.filter {
            it.target == target && it.id !in superseded && matches(it.condition, ctx)
        }

        var value = base
        var forbidden = false
        var requiresCritical = false

        for (layer in Layer.entries) {
            val inLayer = live.filter { it.layer == layer }
            if (inLayer.isEmpty()) continue

            // Additive contributions, clamped per stack group.
            inLayer.filter { it.effect is ModEffect.Flat || it.effect is ModEffect.SetTo }
                .groupBy { it.group }
                .forEach { (group, ms) ->
                    val raw = ms.sumOf {
                        when (val e = it.effect) {
                            is ModEffect.Flat -> e.n
                            is ModEffect.SetTo -> e.n
                            else -> 0
                        }
                    }
                    value += if (group == null) raw else raw.coerceIn(-group.cap, group.cap)
                }

            inLayer.forEach { m ->
                when (val e = m.effect) {
                    is ModEffect.Scale -> value = Math.floorDiv(value * e.num, e.den)
                    is ModEffect.Decay -> {
                        val remaining = e.from + e.perTurn * ctx.turn
                        value += if (e.from < 0) minOf(remaining, 0) else maxOf(remaining, 0)
                    }
                    is ModEffect.Cancel -> {
                        val penalty = live.filter { it.source.kind == e.of }
                            .sumOf { (it.effect as? ModEffect.Flat)?.n?.coerceAtMost(0) ?: 0 }
                        value += minOf(e.upTo, -penalty)
                    }
                    ModEffect.Forbid -> forbidden = true
                    ModEffect.RequireCrit -> requiresCritical = true
                    else -> Unit
                }
            }
        }

        return Resolution(value, forbidden, requiresCritical, live.map { it.id })
    }

    private fun matches(c: Condition, ctx: Context): Boolean = when (c) {
        Condition.Always -> true
        Condition.AtNight -> ctx.isNight
        Condition.InDarkness -> ctx.isDarkness
        is Condition.AgainstLowerSequence -> ctx.sequenceDelta >= c.delta
        is Condition.All -> c.of.all { matches(it, ctx) }
        is Condition.Any -> c.of.any { matches(it, ctx) }
    }
}
```

```kotlin
import com.pathways.model.DiceExpr

/** Ch. 2, p. 7. Roll 3d6, succeed on equal or under. */
object SuccessRoll {

    private val THREE_D_SIX = DiceExpr(3, 6, 0)

    fun against(target: Int, source: RandomSource): RollResult =
        evaluate(THREE_D_SIX.roll(source), target)

    fun evaluate(total: Int, target: Int): RollResult {
        val margin = target - total
        val outcome = when {
            total <= 4 -> Outcome.CRITICAL_SUCCESS
            total >= 17 -> Outcome.CRITICAL_FAILURE
            margin <= -10 -> Outcome.CRITICAL_FAILURE
            margin >= 0 -> Outcome.SUCCESS
            else -> Outcome.FAILURE
        }
        return RollResult(total, target, margin, outcome)
    }
}
```
